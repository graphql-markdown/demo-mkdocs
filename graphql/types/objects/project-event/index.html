ProjectEvent

A change delivered to subscribers watching a project.

type ProjectEvent {
  type: ProjectEventType!
  project: Project!
  actor: User
  occurredAt: DateTime!
}

Fields

ProjectEvent.type ● ProjectEventType! non-null enum

The kind of change that occurred.

ProjectEvent.project ● Project! non-null object

The project in its state after the change.

ProjectEvent.actor ● User object

The user who triggered the change, when known.

ProjectEvent.occurredAt ● DateTime! non-null scalar

When the change occurred.

Example

{
  "type": "UPDATED",
  "project": {
    "id": "project_01",
    "name": "Mobile Refresh",
    "status": "ACTIVE"
  },
  "occurredAt": "2026-09-05T10:15:00Z"
}
